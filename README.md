# Digital Clock

A simple responsive digital clock built with HTML, CSS, and JavaScript. It displays the current local time over a city background, with a centered glass-style clock panel.

## Features

- Displays the current time in `HH:MM:SS` format.
- Updates every second.
- Responsive layout for mobile screens.
- Full-screen background image with a translucent glass effect.
- Uses only browser-native HTML, CSS, and JavaScript.

## Run locally

No installation or build step is required. Open `index.htm` in a web browser. For the complete appearance, keep `index.htm`, `index.js`, `style.css`, and `img.jpg` together in the same folder.

## Project files

| File | Purpose |
| --- | --- |
| `index.htm` | Defines the clock page and loads the stylesheet and script. |
| `style.css` | Styles the background, glass panel, clock, and mobile layout. |
| `index.js` | Reads the current time and refreshes the display every second. |
| `img.jpg` | Background image used by the page. |
